## Комментарии к событиям

### Описание
  Реализуем комментарии к событиям.  
  Комментарии можно добавлять, редактировать и удалять.  
  Комментарии могут добавлять только пользователи у которых одобрили заявку на участие.  
  Редактировать и удалять может только автор комментария.   
  Видеть комментарии к событию могут все.  
  Отдельно получить список своих комментариев к событиям может каждый автор.   

### Таблица в БД
   CREATE TABLE IF NOT EXISTS comments (  
   id 			INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,  
   event_id		INTEGER REFERENCES events (id) ON DELETE RESTRICT,  
   author_id		INTEGER REFERENCES users (user_Id) ON DELETE RESTRICT,  
   text 		    VARCHAR(1000),  
   creation_date TIMESTAMP  
   );  
   COMMENT ON TABLE comments IS 'Таблица хранит комментарии';
   COMMENT ON COLUMN comments.id IS 'Уникальный идентификатор комментария';
   COMMENT ON COLUMN comments.event_id IS 'Идентификатор события';
   COMMENT ON COLUMN comments.author_id IS 'Идентификатор автора';
   COMMENT ON COLUMN comments.text IS 'Текст комментария';
   COMMENT ON COLUMN comments.creation_date IS 'Дата и время создания комментария';
